Rates per 1M tokens

Sync is the per-token rate for real-time requests. Async and Batch bill a fixed share of it for work that can wait. Cached input is the rate for prompt prefixes served from cache.

Cached input

Prompt prefixes served from cache bill at the cached input rate. It applies automatically, with no configuration. How to structure prompts so they hit the cache.

Request features

Supported request features do not add a separate fee. Each request is metered on input and output tokens at the model's rates.

Batch at 50% off

The Batch Inference API bills half the Sync rate, with results within 24 hours. An expedited batch bills the Sync rate. Rate-for-rate comparisons against Gemini's batch mode and Bedrock batch inference are in the provider guides.

Async at 20% or 50% off

Async takes single requests and delivers the results within a window you pick: 20% off Sync within 1 hour, 50% off Sync within 24 hours. It runs on the models the table below lists it for. The Async docs cover how to submit a job.
